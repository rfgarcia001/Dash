API de Ingestão

Como automações externas — hoje, N8N — escrevem dados de anúncios, vendas e criativos direto no Postgres que serve o dashboard. O dashboard nunca escreve nessas tabelas, só lê.

◆
Por que essa API existe: antes, o dashboard lia tudo direto do Google Sheets a cada carregamento — frágil e sempre um pouco atrasado. Migramos a fonte de dados pra Postgres nesta API, pra que a mesma automação que já existe escreva direto no banco, com dado quase em tempo real.

Escopo: só o ambiente da VPS (rfgarcia001/Dash). O ambiente AWS continua lendo do Google Sheets e não usa esta API.

Autenticação

Todo endpoint espera este header:

X-Ingest-Token: <token>

Diferente do usuário/senha do dashboard — aquele é credencial de humano navegando no browser, este é credencial de automação (configurado via INGEST_API_TOKEN no servidor). Guarde como credencial no N8N (Header Auth), nunca em texto puro no workflow.

401token inválido ou ausente
503ingestão desligada no servidor

funnelId

Todo endpoint (exceto a listagem) precisa de um funnelId — o identificador do funil já cadastrado no dashboard. Descubra o valor certo consultando GET /api/ingest/funnels. Se o funil ainda não existe, cadastre primeiro pela tela "Novo funil" no dashboard antes de configurar a automação.

GET /api/ingest/funnels

Listar funis

Retorna todos os funis cadastrados no dashboard, pra quem está montando uma automação nova encontrar o funnelId certo.

✓
Caso de uso
Antes de configurar uma automação nova no N8N, descobrir o funnelId exato sem precisar abrir o dashboard ou pedir pra outra pessoa.

Resposta

{
  "funnels": [
    { "id": "estrategia", "name": "Livro Estratégia em Ação" },
    { "id": "gestao-ia", "name": "Livro Gestão de Projetos com IA" }
  ]
}

Erros

401token inválido/ausente
503ingestão desligada

Gravar dados do Meta Ads

Grava gasto, impressões e cliques de um dia de anúncios pra um funil.

⟳
Caso de uso
A automação do N8N roda a cada 30 minutos, puxa gasto/impressões/cliques do dia atual direto da API do Meta Ads, e sincroniza com o Postgres. O dashboard mostra o gasto de hoje quase em tempo real, sem depender de uma rotina de planilha rodando à noite.
↻
Cada chamada substitui o dia inteiro daquele funil (apaga e regrava as linhas de date) — reenviar o mesmo dia não duplica. Dentro do lote, cada linha faz upsert por adId.

Corpo da requisição

{
  "funnelId": "estrategia",
  "date": "2026-09-01",
  "rows": [
    {
      "adId": "120248842417980056",
      "campaignName": "[MARIO][PERPÉTUO][LIVRO][ESTRATÉGIA EM AÇÃO][PMO&VMO] [1]",
      "adsetName": "[AD026-030] [ADV+Aberto]",
      "adName": "[AD029] [IMG] [VD] [PMO&VMO] [PERPÉTUO]",
      "spend": 48.49,
      "impressions": 2019,
      "linkClicks": 26,
      "landingPageViews": 23,
      "initiateCheckout": 0,
      "creativeThumbUrl": ""
    }
  ]
}

rowsarrayobrigatóriopode ser []
rows[].adIdstringrecomendadosem dedup no lote

Resposta

Caso de uso

Gravar um criativo

Grava nome, link e thumbnail de um criativo de anúncio.

▣
Caso de uso
Depois que um criativo novo entra no ar no Meta Ads Manager, a automação detecta e envia nome/link/thumbnail pro banco — a aba de criativos do dashboard atualiza sozinha, sem copiar link do Instagram manualmente.
+
Upsert por (funnelId, creativeName) — nunca apaga, só adiciona/atualiza. A origem só devolve os anúncios ativos numa janela recente; um "substituir tudo" apagaria criativos antigos ainda relevantes.

Corpo da requisição

{
  "funnelId": "estrategia",
  "rows": [
    {
      "creativeName": "AD029",
      "link": "https://instagram.com/p/xyz",
      "thumbUrl": "https://scontent.xx.fbcdn.net/.../thumb.jpg"
    }
  ]
}

CampoTipoSe ausente

rowsarrayobrigatóriopode ser []
rows[].creativeNamestringobrigatóriolinha ignorada
rows[].link / thumbUrlstringopcional""

Resposta

Fluxo completo — exemplo Meta Ads

Schedule Trigger (N8N, a cada 30 min)
dispara a automação periodicamente
Meta Ads Insights API
busca gasto/impressões/cliques do dia
Code node — agrupa por anúncio
calcula métricas, monta o payload
POST /api/ingest/meta
esta API
Postgres — tabela meta_ads
grava, substituindo o dia inteiro
Dashboard
lê via SELECT, mostra o gasto quase em tempo real

O mesmo padrão se repete pras vendas (webhook em vez de schedule) e pros criativos (schedule diário).

Testando com curl

# substitua <host> e $INGEST_API_TOKEN pelos valores reais
curl -X POST https://<host>/api/ingest/meta \
  -H "X-Ingest-Token: $INGEST_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"funnelId":"estrategia","date":"2026-09-01","rows":[{"adId":"TESTE-1","campaignName":"Teste","spend":10}]}'
